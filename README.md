# 🌍 Climate Action Learning App

An interactive web-based learning application designed to raise awareness of climate change, sustainability, and the United Nations Sustainable Development Goal 13 (Climate Action).

Developed as a group academic project at Universiti Malaysia Sarawak (UNIMAS), this application combines educational content, interactive quizzes, instant feedback, and a reward system to create an engaging learning experience.

## 📌 Project Overview

The Climate Action Learning App helps users learn about climate change and environmental sustainability through short learning modules and interactive quizzes.

Users can explore educational topics, test their knowledge, earn points, receive achievement badges, and review quiz results through a leaderboard.

## ✨ Key Features

- **Learning Modules:** Explore 10 educational topics covering climate change, its causes and effects, renewable energy, sustainable living, and climate action.
- **Interactive Quiz:** Answer 20 multiple-choice and true-or-false questions to test your knowledge.
- **Instant Feedback:** Receive immediate feedback after submitting each answer, including the correct answer when a response is incorrect.
- **Score Tracking:** Track quiz scores, percentages, points, and completion time.
- **Reward System:** Earn experience points (XP) and achievement badges based on quiz performance.
- **Hearts System:** Start each quiz with five hearts and lose a heart for each incorrect answer.
- **Leaderboard:** View recorded quiz results, including usernames, scores, points, badges, and completion times.
- **Responsive User Interface:** Access the application through a clean, interactive interface designed to adapt to different screen sizes.

## 🚀 How to Run the Project

No database or backend server is required to run this application locally.

1. Download or clone this repository.
2. Ensure that `index.html`, `style.css`, and `app.js` are in the same folder.
3. Open `index.html` in a web browser.
4. Click **Get Started** to begin exploring the application.

Alternatively, open the project folder in Visual Studio Code and use the Live Server extension.

**Note:** An internet connection is required to load the Nunito font from Google Fonts. The application can still run using system fonts if the external font is unavailable.

## 💾 Data Storage

The application uses browser Local Storage to save quiz results and display leaderboard records.

The stored results remain in the current browser's local storage and are not automatically synchronised between different devices or users.
